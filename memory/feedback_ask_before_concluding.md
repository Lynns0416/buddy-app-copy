---
name: Ask questions before concluding
description: Don't give confident recommendations without enough information — ask clarifying questions first
type: feedback
---

Ask questions until confident enough, rather than stating recommendations with false confidence.

**Why:** In a session about domain setup, gave multiple wrong instructions (wrong org domain assumption, recommended Cloudflare subdomain delegation without knowing it's Enterprise-only, redirected user away from the correct page). Each mistake came from concluding too early without enough context.

**How to apply:** When missing information that would change the recommendation — especially about third-party services, UIs, plan tiers, or anything that changes over time — ask first. Never present a recommendation as settled when it's based on unverified assumptions.
